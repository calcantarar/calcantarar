# Hi, I'm César Alcántara Ríos

### Microbiology student | Computational Biology | Biotechnology enthusiast

I'm a senior undergraduate in **Microbiology & Parasitology** at [UNMSM](https://www.unmsm.edu.pe/) (Lima, Peru), building a hybrid profile between the **wet lab** and the **terminal**. My work sits at the intersection of **computational protein design**, **microbial genomics**, **molecular biology**, and **biotechnology** using code to understand and study biological systems.
